📖 操作说明

🖱️ 鼠标操作

左键单击添加一个标注点（点模式下）
左键拖拽画矩形框选（矩形模式下）
按住已有矩形拖动矩形位置；拖动边界圆点调整大小
左键拖拽空白平移图片（点 / 十字模式下）
右键标注点/框删除该标注
中键拖拽平移图片（任何模式下都可用）
滚轮缩放图片（以鼠标位置为中心）

⌨️ 快捷键

1 / 2 / 3 / 4切换标注类型：牛 / 马 / 羊 / 骆驼
+ / -放大 / 缩小
0复位视图（重置缩放和平移）
F进入 / 退出图片全屏显示
Space + 拖矩形模式下临时平移图片
Enter确认当前图片并进入下一张
← / →上一张 / 下一张图片
Esc关闭弹窗

🎨 标记样式

大小：S / M / L标注点的尺寸
字号滑块控制数字/类型标签的字号（5-22px）
● 圆点最简洁，密集场景推荐
●N 圆点+数字带序号，方便核对数量
✚ 十字定位精准，不挡视野
▢ 矩形+数字一个矩形 = 1 个计数，带角标
▢字 矩形+标签矩形上方居中显示「类型+7位ID」（如 牛 i25im8b）
□ 纯矩形无数字标记，画面最干净

📋 工作流

1. 导入图片选择整个文件夹，或自选一张 / 多张图片
2. 标注在每张图上点击 / 画框标记牛、马、羊或骆驼
3. 确定点 ✓ 或按 Enter 记录当前图，自动跳下一张
4. 调整显示图片默认保持原比例并居中；画布宽度可调为页面的 60%-100%，高度可调为屏幕的 45%-85%
5. JPEG 质量结果表下方可在 40%-100% 之间设置标注 JPEG 的清晰度与文件大小
6. 指定目录选择图片输出文件夹，并可勾选“设为默认”供下次使用
7. 导出可修改文件名并保存原图或标注 JPEG；重名文件会自动追加序号，避免覆盖
